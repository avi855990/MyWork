# Distributing Busting in Space

To send the game to someone who does not have Python, build it first.

## macOS

Double-click:

```text
Build macOS App.command
```

Then send:

```text
dist/Busting in Space macOS.zip
```

## Windows

Build this on a Windows computer. Double-click:

```text
Build Windows EXE.bat
```

Then send the whole folder:

```text
dist\Busting in Space Windows.zip
```

The Windows build must be made on Windows. The macOS build must be made on macOS.
